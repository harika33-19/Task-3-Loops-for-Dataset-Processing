# Task-3-Loops-for-Dataset-Processing
Python for loops and while loops for dataset processing using a Student Marks Dataset, including total, average and summary statistics.

## Data Science Internship – Veda Technology

This project focuses on practicing Python `for` loops and `while` loops for basic dataset processing using a sample Student Marks Dataset.

## Objective

* Understand iteration using loops.
* Process numerical values.
* Calculate totals and averages.
* Find summary statistics using loops.
* Practice iterating through lists and dictionaries.

## Tools Used

* Python
* Google Colab
* Jupyter Notebook

## Dataset

A sample Student Marks Dataset containing 10 students and their marks.

## Tasks Performed

* Displayed student marks using for loops.
* Used `range()` for controlled iteration.
* Calculated total and average marks.
* Found maximum and minimum marks.
* Categorized student performance.
* Processed data using while loops.
* Calculated summary statistics, including pass and fail counts.

## Key Learnings

* Python loops
* List and dictionary iteration
* Conditional statements
* Basic statistical calculations
* Dataset processing

## Conclusion

This task provided practical experience with Python loops and demonstrated how repetitive data processing and basic statistical calculations can be automated.
